02 Set the pace

🕵️ Hidden-role round

Meetings happen automatically (and only if someone was tagged), pause chats by default (saved, nothing lost) so the class talks it over, then everyone votes privately within the window. Uncheck the box above for asynchronous voting. The crew wins when everyone together finishes the target share of tasks (ghosts\u2019 answers count too), or by voting out every impostor. Impostors win if the optional timer runs out, or if they reach parity with the living crew. Impostors follow the Among Us ratio (about one per four players, at least one) and get 2 tags for each finished chat. Nobody can be tagged while in a chat or for a few seconds after leaving one. Minimum 4 players.

No elimination. No lost progress. Timers prompt a next step; they never punish a learner for needing help.
